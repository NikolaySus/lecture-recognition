# Многомодельный benchmark одного лектора

Runner реализует шаги A–C roadmap: переносимую оценку, сравнение исходных
моделей и ограниченный словарный пилот. Это диагностическая серия на R001–R008,
не независимый test и не обучение. Результаты запусков описываются отдельно
в отчёте исполнения; наличие кода не означает завершения экспериментов.

## Воспроизведение

```bash
uv sync --locked
uv sync --locked --project experiments/gigaam
uv sync --locked --project experiments/parakeet
uv run --locked python scripts/benchmark_models.py all record/20260925_101716.m4a \
  --review record/20260925_101716.review.md
```

Этапы можно запускать отдельно: `prepare`, `smoke`, `baseline`, `compare`,
`bias`, `full`, `report`. `compare` сначала воспроизводит baseline;
`bias` выполняет недостающие сравнения; `full` при отсутствии решения
сначала выполняет пилот. `all` также проверяет каждую модель на 20 секундах.

`--models qwen whisper` ограничивает состав сравнительной серии; Qwen baseline
остаётся обязательным. `--output` меняет каталог результатов. `--config`
принимает JSON с полями `models` и `dictionaries`; полный снимок значений
по умолчанию сохраняется в `config.json` каждого запуска. Неудачные случаи
сохраняются; `--retry-failed` разрешает повтор после устранения причины.

Корневой lock-файл сохраняет изменения пользователя. GigaAM изолирован от
Transformers проекта: используется 4.57.1 с torch/torchaudio 2.9.1 cu128.
Это отличается от рекомендованного в карточке GigaAM torch 2.8.0; выбранная
сборка позволяет повторно использовать установленные CUDA-библиотеки,
совместимость подтверждается реальным smoke test, а не предполагается.
`pyannote-core` нужен статической проверке импортов remote code; собственный
VAD GigaAM и закрытые модели PyAnnote не запускаются.
Parakeet использует отдельное окружение NeMo 3.0.0. Все окружения имеют lock-файлы.

Runner удаляет только не поддерживаемую httpx переменную ALL_PROXY со схемой
`socks://` из собственного процесса и дочерних процессов; системные настройки
не меняются. По умолчанию скачивание HF идёт без Xet; явное значение
HF_HUB_DISABLE_XET сохраняется. Остальные настройки прокси сохраняются.

## Данные и сравнение

Сначала декодируется вся запись, выполняется Nemotron и выбирается лектор.
Самостоятельная чужая речь маскируется тишиной. Производственный кэш не нужен.
Эталон первых восьми карточек фиксируется до ASR; остальные карточки не
используются. Рецепт выравнивания эталона сохранён из предыдущего эксперимента.

Qwen получает первые три полных входа производственной нарезки до 120 с.
Остальные модели покрывают тот же префикс: GigaAM — до 20 с,
Whisper — до 30 с, Parakeet — до 60 с. Контекст до секунды с каждой стороны
входит в максимум. Сравнение относится к паре «модель + нарезка».
GigaAM получает float-аудио прямо в энкодер/декодер без повторной PCM16-конвертации.

В ASR-процессы не передаётся текст эталона. Их исходный текст сохраняется
до общего Qwen ForcedAligner. Нативные таймкоды, если есть, сохраняются отдельно.
WER/CER считаются на фиксированных окнах трёх объединённых участков;
пересекающиеся карточки не суммируются. Сбой выравнивания не уничтожает ASR,
не получает фиктивный WER и не участвует в выборе.

Нормализация сохраняет повторы и отрицания, различает 124/1024 и «или»/диапазон.
Дополнительные показатели: S/D/I, ошибки чисел и отрицаний, precision/recall
словарных семейств, лишние термины. Precision/recall здесь основаны на счётчиках
лексических семейств в каждом окне, не на акустическом подтверждении слов.
Oracle WER выбирает модель отдельно для каждого целого участка с доступом
к эталону; это только диагностика взаимодополняемости.

## Словарный пилот и выбор

До генерации фиксируются короткий словарь, вариант с двумя формами
«квазистационарность» и контроль из трёх отсутствующих в эталоне терминов.
Для двух лучших поддерживаемых баз: Qwen/Whisper используют prompt;
Parakeet — GPU-PB с alpha 0.5/1/2. GigaAM участвует в сравнении баз,
но не получает экспериментальный новый декодер.
В закреплённом NeMo 3.0.0 нет параметра `bpe_mode` из nightly-документации:
используется штатный `BoostingTreeModelConfig`, русский язык и явные варианты
с маленькой/первой заглавной буквой. Фактический список сохраняется в случае.

Преимущество словаря принимается только при снижении WER без потери ранее
правильных чисел/отрицаний и без роста лишних терминов. Дополнительно
проверяются контрольный словарь, повтор и изменённые границы.
Для Qwen внутренние границы сдвигаются на +5 с с ограничением допустимой
длины; для коротких входов первая граница сдвигается раньше на 5 с,
последующие пересчитываются по тишине. Фактические границы сохраняются.

Общий рейтинг: WER, число ошибок на защищённых позициях, время ASR, ID случая.
Если лучшая новая база/безопасный словарь не улучшает WER Qwen, остаётся Qwen.
Выбранный режим обрабатывает полную лекцию в отдельный SRT. Проверяется
временная шкала, максимальная длительность блоков и отсутствие пересечений
с самостоятельной чужой речью. WAV для прослушивания используют исходное
аудио и исходные координаты; ручная приёмка не выполняется автоматически.

## Артефакты и проверки

Результаты: `.lecture-cache/model-benchmark/<run-id>/`. Каждый случай содержит
запрос без эталона, `asr/result.json`, исходные тексты по чанкам,
`alignment/result.json`, `case.json`, логи и отдельный `transcript.srt`.
В корне — метаданные, снимок эталона, конфигурация, `summary.json`,
`comparison.md`, решения о выборе. `listening/manifest.json` описывает WAV.

Хэши исходного аудио, разметки, кода и lock-файлов определяют запуск.
Словарь, параметры, границы и повтор определяют отдельный случай.
Время ASR включает загрузку моделей в GPU, но не скачивание весов;
`download_seconds` сохраняется отдельно. `cached_chunks` показывает частичное
возобновление; для таких случаев время в рейтинге считается недоступным.
OOM не вызывает скрытого уменьшения чанка, batch или изменения точности.

```bash
uv run --locked pytest -q
uv run --locked ruff check src tests scripts
```

На данной машине до изменений падали три теста фильтров afftdn:
FFmpeg 4.4.2 возвращает 31600 вместо 32000 отсчётов. Эти фильтры не используются
в серии и не исправляются данным изменением. Остальные проверки должны проходить.
