# Предобработка: проверка «квазистационарности»

Эксперимент 25 сентября 2026 года на `record/20260925_101716.m4a`,
NVIDIA RTX 4060 Laptop 8 ГБ, Qwen3-ASR-1.7B-hf BF16/CUDA.
Использованы закреплённые в проекте ревизии моделей и диаризация всей лекции.
Аудио для опытов ограничено первыми 300 секундами; исходный SRT не изменён.

## Результат

**Ни одна из 22 конфигураций не прошла точный тест.**
20 конфигураций завершили распознавание и выравнивание; две были отклонены
до ASR из-за увеличения сверхпиковых отсчётов после шумоподавления.
Пиковая и RMS-нормализация с ограничением пика дали одинаковое аудио,
поэтому повторный результат использован из кэша.

Самый близкий по содержанию результат — левый канал на исходных границах:
«мы можем принять гипотезу **квази стационарности**». Слово оказалось разделено
пробелом: это **не успех** по согласованному критерию. На том же канале с
90-секундным контекстом получилось «в базе стационарности».
Оснований менять рабочую предобработку по этому эксперименту нет.

| Вариант | Результат в целевом интервале |
|---|---|
| Исходный рабочий чанк | «о стационарности» |
| Контекст 60 или 90 секунд | «базе стационарности» |
| Контекст 118 секунд | «о базе стационарности» |
| Левый канал, рабочие границы | «квази стационарности» |
| Левый канал, 90 секунд | «в базе стационарности» |
| Правый канал, рабочие границы / 90 секунд | «базе стационарности» / «базис стационарности» |
| Пиковая и RMS-нормализация | «о стационарности» |
| High-pass 80 Гц | «о стационарности» |
| Полоса 80–7000 Гц | «о базе стационарности» |
| High-pass + шумоподавление 6 dB | «о базе стационарности» |
| Компрессор | «о стационарности» |
| Нормализация и high-pass × контексты 60/90/118 секунд | «базе стационарности» либо «о базе стационарности» |
| Шумоподавление 6/12 dB без high-pass | Отклонено до ASR; не является результатом проверки распознавания |

Суммарное время конфигураций — **1485,15 с (24,75 минуты)**, включая обработку,
загрузку моделей и выравнивание; начальный технический перезапуск сюда не входит.
Пик GPU-памяти завершённых вычислений — до **4,68 ГиБ**.
Время повторов из кэша нельзя использовать для сравнения скорости фильтров.

## Условия и ограничения

- Точное слово в исходном ответе ASR, без учёта регистра и окружающей пунктуации;
  положительный интервал слова и его середина в `[145,155]` секунд.
- Никаких словарей, подсказок термина, склеивания частей или исправления текста.
- Основная часть чанка не короче 60 секунд; ASR-вход с перекрытиями не длиннее 120.
- Greedy decoding, русский язык, batch size 1, без скрытого аварийного деления.
- После обработки чужая речь снова маскируется нулями; длина аудио сохраняется.
- Исходный декодированный AAC содержит пять отсчётов за уровнем ±1, максимум
  модуля 1,07025. Контроль сохраняет их; фильтры, увеличивающие этот максимум,
  отклоняются. В начальном запуске проверка ошибочно отклоняла сам контроль;
  она исправлена, итоговая матрица выполнена заново в версии эксперимента 2.
- После точного попадания предусмотрены проверки со сдвигами границ ±5 секунд
  и полного префикса с batch size 2. Попаданий не было, поэтому эти проверки
  не запускались. Исчерпана матрица из 22 конфигураций, а не общий лимит 30.

Это результат проверки одного термина, **не WER и не оценка всей лекции**.
Разница между «квази стационарности» и пропуском «квази» показана отдельно,
хотя строгий бинарный тест отвергает оба варианта.
