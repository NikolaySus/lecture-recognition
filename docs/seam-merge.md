# Сопоставление полного перекрытия: contextual

Обновлено: 2026-10-06. Реализация первого варианта без нового ASR и обучения.

## Правила

Legacy `current` сохранён. Новый режим `contextual` начинает с его результата,
затем сопоставляет все лексические токены реального аудиоперекрытия соседних
чанков монотонным SequenceMatcher. Совпадение может находиться внутри текста,
а не только на суффиксе/префиксе. Эталон не передаётся алгоритму.

Удаляются только повторные представления уже сохранённых токенов, когда есть
временное совпадение или минимум два независимых временных якоря в общем
контексте. Дополнительное правило обрабатывает уникальную длинную фразу с
оборванным конечным словом либо очень короткой составной единицей и разницей
окончаний на краю входа. Выбирается распознанная копия с полным продолжением;
новые слова не сочиняются. Числа, отрицания и самостоятельные короткие слова
не считаются обрезанными окончаниями. Спорные повторы сохраняются в audit
как `contextual_ambiguous_repeat`.

Слова внутри составной единицы не получают придуманных временных отметок.
При частичном удалении её исходный интервал сохраняется. Исправление текста
не подтверждает точность этого интервала. Истинные повторы проверяются отдельно.

## Результат

Сравнены 26 раскладок + 4 сдвига на R001–R008 (246 слов). Все legacy оценки
воспроизведены перед пересчётом. Нет ухудшений ни в одной карточке или группе;
сохранены ранее правильно распознанные защищённые числа/отрицания. Все SRT
сформированы успешно. S001–S012 не использовались при разработке.

| Случай | current, ошибок | contextual, ошибок | WER contextual |
|---|---:|---:|---:|
| RNNT regular 20/context 2, 0 с | 16 | 14 | 5,69% |
| CTC regular 20/context 2, +2 с | 22 | 17 | 6,91% |
| RNNT regular 20/context 2, +2 с | 27 | 22 | 8,94% |
| CTC regular 20/context 2, 0 с | 11 | 11 | 4,47% |

Остальные 27 оценок не изменились. Повтор в R001 (+2 с) устранён у обеих
моделей, «а именно» в R002 (0 с) — у RNNT. Ошибки raw ASR, включая пропуск
«ряда», не исправляются этим алгоритмом. Чувствительность к фазе остаётся:
CTC −2 с — 19 ошибок, RNNT −2 с — 22; это не доказательство общей устойчивости.

Проверено 113 тестов: истинные повторы, составные единицы, контекстные якоря,
обрезанные слова, спорные полные окончания, числа/отрицания, сохранность входа,
границы, отсутствие перекрытия и продолжение CLI с выбранной склейкой.


выбранную склейку из latest.json; для воспроизводимости её можно указать явно.
